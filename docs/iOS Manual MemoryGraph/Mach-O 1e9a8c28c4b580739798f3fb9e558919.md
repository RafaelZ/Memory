# Mach-O

文件结构：

- header
- load commands
    - LC_SEGMENT_64
        - Section64 Header (pagezero)
            - vm add 0x00000000000
            - vm size 0x00001000000
        - Section64 Header (data)
            - vm add 0x00001000000
            - vm size 312736767
        - Section64 Header (text)
        - Section64 Header (const)
        - …
    - LC_SEGMENT_64
        - Section64 Header 2.1
        - Section64 Header 2.2
- data
    - section
    - section
    - section
    - …
- …
- Dynamic Loader Info
- Function Stars
- Symbol Table
- Dynamic Symbol Table
- String Table
- code signature

mach-o 布局是按段(segment)来分的，段内又分区(section)

load commands 部分是对段的描述（LC_Segment_64），name、起始地址、size
